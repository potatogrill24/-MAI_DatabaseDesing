# Проектирование баз данных

Лабораторные работы на PostgreSQL. [Создание баз и восстановление дампа](database_create/README.md).

| Лабораторная | Содержание |
|---|---|
| [1](lab_01/README.md) | Выборки, группировка, соединения и JSON-документы |
| [2](lab_02/README.md) | Банковские переводы и журнал операций |
| [3](lab_03/README.md) | Транзакции и триггер суммы бронирования |
| [4](lab_04/README.md) | Индексы, курсоры и планы выполнения |
| [5](lab_05/README.md) | Статистика и оценка кардинальности запросов |
| [6](lab_06/README.md) | Оптимизация поиска пассажиров задержанных рейсов |

В каждой директории — SQL-скрипты, инструкции и протоколы выполнения в `results`.
